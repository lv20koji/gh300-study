# 資格勉強ポータル

GH-300（GitHub Copilot）と応用情報技術者試験の対策用 学習 Web アプリ。忘却曲線に沿った復習（SM-2）、弱点集中、ミニテスト、フラッシュカード、学習記録を 1 つのポータルにまとめた静的 PWA です。

- 公開サイト: https://lv20koji.github.io/gh300-study/
- 問題はすべてオリジナル（GH-300 60 問／応用情報 30 問）。各問に間違い理由（wrongNote）と出典ライン付き。
- 学習データはブラウザの localStorage にのみ保存され、外部送信されません。
